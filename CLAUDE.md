# Russian Grammar Project

Single-page ("Itsunekko style") HTML grammar guide built from *The New Penguin Russian Course* (Nicholas J. Brown).

- **Source PDF**: `Russian Course (Bookmarks).pdf` in the repo root. It is gitignored and lives only in the local working folder. 523 pages, scanned; its built-in OCR layer is English-only and wrong for every Cyrillic word.
- **Page offset**: PDF page = printed book page + 8. Lesson start pages are in the PDF bookmarks. Grammatical Tables = PDF pp. 386–395.
- **Issue tracker**: GitHub Issues. See `docs/agents/issue-tracker.md`.
