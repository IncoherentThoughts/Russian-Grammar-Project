# Russian Grammar Project

A single self-contained HTML page built from *The New Penguin Russian Course* (Nicholas J. Brown): all 30 lessons trimmed to explanations, example sentences and dialogues, with a jump-to table of contents and the book's Grammatical Tables hoisted to the top for quick reference.

**Live page:** https://incoherentthoughts.github.io/Russian-Grammar-Project/ (also works opened locally: `index.html`, fonts are embedded).

## Layout

- `transcripts/pNNN.md` — one Markdown transcript per PDF page (PDF page = printed page + 8), stress marks as U+0301. Hand-correct these.
- `transcripts/key.md` — English translations of dialogues/texts harvested from the Key (generated by `scripts/harvest_key.py`).
- `prompts/transcribe.md` — the transcription rules the page transcripts follow.
- `scripts/build.py` — stitches the transcripts into `index.html`, applying the cut rule (vocabulary lists, exercises, handwriting) and inlining fonts from `assets/fonts/`.
- `CONTEXT.md` — glossary of the terms used in the transcripts and build.

## Rebuild

```bash
.venv/bin/python scripts/build.py
```

Commit the resulting `index.html`; GitHub Pages serves `main` from the repo root.
