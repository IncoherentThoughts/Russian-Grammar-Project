без двадцати́ де́вять — twenty to nine
Сейча́с без двадцати́ пяти́ пять. — It is now twenty-five to five.

As in English, if the number does not divide by five, it is normal to add the word for 'minutes' (мину́та: мину́ты (gen.sg.) /мину́т (gen.pl.)).

It is nineteen minutes to one. — Без девятна́дцати мину́т час.
It is now one minute to four. — Сейча́с без одно́й мину́ты четы́ре.
